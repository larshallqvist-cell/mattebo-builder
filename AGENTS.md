# Project architecture rules

- Microphone level meters analyze live audio locally through Web Audio only while voice input or the pre-test microphone check is active, stopping tracks and closing the audio context on stop/unmount; never record or upload meter audio. Tabelltestet keeps the same meter mounted from pre-test checking into the test and starts speech recognition on the Start click, so permission and audio levels can be checked before timing begins.
- Tabelltestet restarts unexpectedly ended speech sessions with bounded backoff and a fresh utterance handler; explicit stops and terminal recognition errors never restart, preventing silent loss of listening without retry loops. Stable tens use a longer finite debounce to allow compounds without waiting indefinitely for browser final results.
- Natural speech-session endings retain the last pending candidate's original debounce; explicit stops cancel all session handlers, including those draining during reconnection. Transcript feedback includes consumed-result revisions without grading them again, keeping browser output visible without duplicate answers.
- Speech results may grow across questions at the same result index: retain the accepted transcript prefix with punctuation normalized to word boundaries and grade only a separator-delimited appended answer, with the same stability delay; never regrade a revised prefix, an unseparated digit correction, or guess the first number from several unconsumed numeric tokens, because browser punctuation revisions must not lose or duplicate answers.

- Cache quota-limited Google Sheets reads in the server-only `google_sheet_cache` table; frontend clients must never access this cache or connector credentials.
- The private teacher Bråklabbet is a separate owner-only app; reach it only as an external admin link via `PRIVATE_BRAKLABBET_URL`, never embed that URL, so its own access rules stay in charge.
- The student Bråklabbet (owner-authorized copy of the generic lab) lives only in `supabase/functions/braklabbet-content/source/`, bundled by `scripts/build-braklabbet-content.mjs` into `content.ts` and served only after server-side checks in `access.ts`; `/braklabbet` renders it in a sandboxed `srcDoc` iframe without `allow-same-origin` or tokens, so it is never a public asset. Mission progress cannot live inside that sandbox; the iframe reports completions over `postMessage` and `src/pages/Braklabbet.tsx` persists them in `public.braklabbet_progress` (RLS: own rows only), never by passing tokens into the iframe.
- Grade-page navigation stays in document flow with a wrapping second row for lesson controls; this reserves its actual height and prevents overlap at narrow widths or enlarged text sizes.
- Fraction training keeps its exercise/grading source in the protected lab, with a generated `_shared/braklabbet-exercises.js` copy for deployment; common access decisions live in `_shared/braklabbet-access.ts`. Only the server records attempts, computes correctness and atomic attempt numbers, and deduplicates retries by request ID. Students read own attempts and existing admins read all through RLS; the parent relays answers and minimal results without iframe tokens. Training RLS checks the protected roles table directly because `has_role` is not executable by client roles.
- Tabelltestet (`/tabelltestet`) is a plain React page, not part of the sandboxed lab; pass rules and question generation live in `src/lib/tabelltest.ts` with bun tests in `tests/tabelltest.test.ts`. Results go to `public.tabelltest_results` (RLS: own rows, admin reads all) and the admin list only ever shows to admins. Continuous speech recognition calls the latest answer callback through a ref so it never grades against a previous question; `src/lib/tabelltestVoice.ts` accepts stable interim numbers and deduplicates by utterance index so delayed final events never answer the next question. `tests/tabelltest-voice.e2e.py` covers one full continuous session without storing test results.- Algebra (/algebra) is a plain client-side React page; generation and answer checking live in src/lib/algebra.ts with exact fractions, tested in tests/algebra.test.ts. Each graded answer is logged to public.algebra_attempts (RLS: own insert by approved users, admin reads all); stats/level-status rules live in src/lib/algebraStats.ts, tested in tests/algebraStats.test.ts.
