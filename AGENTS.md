# Project architecture rules

Subdirectories have their own `AGENTS.md` (e.g. `src/lib/AGENTS.md`); read it before changing files there.

- Student activity is mounted once inside the router for approved non-admin users; foreground interaction estimates pause after 60 seconds idle and start a new visit after 30 minutes away. Only allowlisted page names, visit IDs and seconds are recorded through an authenticated, server-timestamped RPC; no input contents or external browsing are captured. A cross-tab foreground lease prevents simultaneous time counting. Admin-only directory RPC exposes only student names and last sign-in; timelines reuse existing exercise and resource records under admin SELECT policies.

- Cache quota-limited Google Sheets reads in the server-only `google_sheet_cache` table; frontend clients must never access this cache or connector credentials.
- The private teacher Bråklabbet is a separate owner-only app; reach it only as an external admin link via `PRIVATE_BRAKLABBET_URL`, never embed that URL, so its own access rules stay in charge.
- The student Bråklabbet (owner-authorized copy of the generic lab) lives only in `supabase/functions/braklabbet-content/source/`, bundled by `scripts/build-braklabbet-content.mjs` into `content.ts` and served only after server-side checks in `access.ts`; `/braklabbet` renders it in a sandboxed `srcDoc` iframe without `allow-same-origin` or tokens, so it is never a public asset. Mission progress cannot live inside that sandbox; the iframe reports completions over `postMessage` and `src/pages/Braklabbet.tsx` persists them in `public.braklabbet_progress` (RLS: own rows only), never by passing tokens into the iframe.
- Grade-page navigation stays in document flow with a wrapping second row for lesson controls; this reserves its actual height and prevents overlap at narrow widths or enlarged text sizes.
- Fraction training keeps its exercise/grading source in the protected lab, with a generated `_shared/braklabbet-exercises.js` copy for deployment; common access decisions live in `_shared/braklabbet-access.ts`. Only the server records attempts, computes correctness and atomic attempt numbers, and deduplicates retries by request ID. Students read own attempts and existing admins read all through RLS; the parent relays answers and minimal results without iframe tokens. Training RLS checks the protected roles table directly because `has_role` is not executable by client roles.
- Tabelltestet (`/tabelltestet`) is a plain React page, not part of the sandboxed lab; pass rules and question generation live in `src/lib/tabelltest.ts` with bun tests in `tests/tabelltest.test.ts`. Results go to `public.tabelltest_results` (RLS: own rows, admin reads all) and the admin list only ever shows to admins. Continuous speech recognition calls the latest answer callback through a ref so it never grades against a previous question; `src/lib/tabelltestVoice.ts` accepts stable interim numbers and deduplicates by utterance index so delayed final events never answer the next question. `tests/tabelltest-voice.e2e.py` covers one full continuous session without storing test results.
- Algebra (/algebra) is a plain client-side React page; generation and answer checking live in src/lib/algebra.ts with exact fractions, tested in tests/algebra.test.ts. Each graded answer is logged to public.algebra_attempts (RLS: own insert by approved users, admin reads all); stats/level-status rules live in src/lib/algebraStats.ts, tested in tests/algebraStats.test.ts. Next-level encouragement (src/lib/algebraEncouragement.ts, tested) is tracked locally per mode/level from first-try timed exercises, so it never changes saved statistics or moves students automatically.
- Grade pages use one responsive layout (Idag → Resurser → Planering → Verktyg → Mat-t-e; planning in a right column at ≥1024px) built from `CollapsibleSection`, with open/closed state per section in localStorage; avoid duplicating panels per breakpoint so data hooks and widgets mount once.
- No app-shell service worker: public/sw.js is a kill-switch that clears old Workbox caches and unregisters, and src/pwa.ts unregisters leftovers; the manifest is static so the app stays installable while users always load the latest published version.
- Procent (/procent) is a plain client-side React page like Algebra; generation and answer checking live in src/lib/procent.ts (tested in tests/procent.test.ts) and the visual models in src/components/procent/, so tasks stay deterministic to test. Each wrong answer and each finished task is logged to public.procent_attempts (RLS: own insert by approved users, admin reads all) and summarized with the shared algebraStats rules, so admin views treat both modules alike.
