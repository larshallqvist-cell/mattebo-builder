# Component rules
- Class presentations are admin-only: "Åk" opens the uploaded HTML slideshow for the highlighted sub-chapter (`public.section_presentations`, keyed by grade, chapter and book section number; batch uploads match file names via `src/lib/presentations.ts`, tested), falling back to one class-wide Slides link or HTML file (`public.class_presentations`). Files live in the private `class-presentations` bucket and open in a new tab inside a sandboxed iframe without same-origin, so teacher/AI-generated scripts never reach the Mattebo session.
