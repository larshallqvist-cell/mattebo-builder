# Component rules
- Class presentations are admin-only: "Åk" opens the uploaded HTML slideshow for the highlighted sub-chapter (`public.section_presentations`, keyed by grade, chapter and book section number; batch uploads match file names via `src/lib/presentations.ts`, tested), falling back to one class-wide Slides link or HTML file (`public.class_presentations`). Files live in the private `class-presentations` bucket and open in a new tab inside a sandboxed iframe without same-origin, so teacher/AI-generated scripts never reach the Mattebo session. Touch controls (close + next) are injected into the deck by `src/lib/presentationControls.ts`: next fires the ArrowRight keydown decks already use, close posts a message the parent tab verifies by source before closing, so iPads can present without a keyboard.
- Lesson-plan editor autosaves a few seconds after typing stops (rules in `src/lib/lessonAutosave.ts`, tested), saves immediately on lesson switch/tab hide/close, and keeps a local per-lesson backup until a save succeeds, so unsaved text is restored on reopen; saves are serialized so only one calendar sync runs at a time.
