# src/lib rules

## Tabelltestet speech and microphone (tabelltestVoice.ts, Tabelltest page)
- Microphone level meters analyze live audio locally through Web Audio only while voice input or the pre-test microphone check is active, stopping tracks and closing the audio context on stop/unmount; never record or upload meter audio. Tabelltestet keeps the same meter mounted from pre-test checking into the test and starts speech recognition on the Start click, so permission and audio levels can be checked before timing begins.
- Tabelltestet restarts unexpectedly ended speech sessions with bounded backoff and a fresh utterance handler; explicit stops and terminal recognition errors never restart, preventing silent loss of listening without retry loops. Stable tens use a longer finite debounce to allow compounds without waiting indefinitely for browser final results.
- Natural speech-session endings retain the last pending candidate's original debounce; explicit stops cancel all session handlers, including those draining during reconnection. Transcript feedback includes consumed-result revisions without grading them again, keeping browser output visible without duplicate answers.
- Speech results may grow across questions at the same result index: retain the accepted transcript prefix with punctuation normalized to word boundaries and grade only a separator-delimited appended answer, with the same stability delay; never regrade a revised prefix, an unseparated digit correction, or guess the first number from several unconsumed numeric tokens, because browser punctuation revisions must not lose or duplicate answers.

## Level games (Kistan, Sannolikhetslabbet)
- Kistan (/kistan): chest game from Equation Quest as a plain React page; rules, levels, unlocking (levels in order within a world; a new world opens after WORLD_UNLOCK_COUNT solved levels in the previous one) and best-result merging live in src/lib/kistan.ts (tested). Best stars/moves are saved only by `exercise-task` after replaying the move log (public.kistan_progress: own/admin read). kistanAvailable (in gameVisibility.ts) admits students only when the game matrix has Kistan on in a chapter of their class. Whole-side ÷/· is a per-side wrap applied term by term (numbers must divide evenly; a bracket dissolves when its factor becomes 1), and star targets come from the rule-following solver, so every target is reachable. After solving, `solutionCheck` substitutes the numeric solution into the original equation (picture levels without a numeric answer get none) and evaluates both sides from the parsed terms, so the check always matches the level text.
- Sannolikhetslabbet (/sannolikhet) follows the Kistan pattern: fixed levels with stars; task generators, exact checking (fraction/percent/integer), stars and unlocking live in src/lib/sannolikhet.ts (tested in tests/sannolikhet.test.ts), scenes in src/components/sannolikhet/. Best stars/first-try correct are saved only by the `exercise-task` function (public.sannolikhet_progress: own/admin read, no client writes); `sannolikhetAvailable` lives in sannolikhetAccess.ts so sannolikhet.ts stays import-free for the server copy; the game matrix key is `sannolikhet`.
- Geometrigymmet (/geometrigymmet, imported from the Geom Trail project): module 3.1 Prefix och enheter as a plain React streak drill; units, stages, generation, checking, mastery (MASTERY_THRESHOLD in a row) and review scheduling live in src/lib/geometrigymmet.ts (tested in tests/geometrigymmet.test.ts) so thresholds stay adjustable and later 3.x modules can be added beside it. Per-skill progress is one jsonb row per student in public.geometrigymmet_progress, written only by `exercise-task` from server-issued spreads (own/admin read), validated by parseProgress on every read; only the unfinished round is kept per device in localStorage. Game matrix key `geometrigymmet`.
