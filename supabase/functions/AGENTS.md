# Edge function rules

- The student Bråklabbet (owner-authorized copy of the generic lab) lives only in `supabase/functions/braklabbet-content/source/`, bundled by `scripts/build-braklabbet-content.mjs` into `content.ts` and served only after server-side checks in `access.ts`; `/braklabbet` renders it in a sandboxed `srcDoc` iframe without `allow-same-origin` or tokens, so it is never a public asset. Mission progress cannot live inside that sandbox; the iframe reports completions over `postMessage` and `src/pages/Braklabbet.tsx` persists them in `public.braklabbet_progress` (RLS: own rows only), never by passing tokens into the iframe.
- Fraction training keeps its exercise/grading source in the protected lab, with a generated `_shared/braklabbet-exercises.js` copy for deployment; common access decisions live in `_shared/braklabbet-access.ts`. Only the server records attempts, computes correctness and atomic attempt numbers, and deduplicates retries by request ID. Students read own attempts and existing admins read all through RLS; the parent relays answers and minimal results without iframe tokens. Training RLS checks the protected roles table directly (`public.user_roles`); `has_role` was later made executable by client roles in migration 0014, so keep the direct check.
